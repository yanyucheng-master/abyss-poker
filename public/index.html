一、游戏概述

《超限德州 / OVERLIMIT: HOLD'EM》是以无限注德州扑克为基础的双人对战。两名玩家通过下注、弃牌与摊牌争夺筹码；启用技能系统时，还可使用赛前装备的技能影响资源、信息、牌面和结算。

任意一方筹码归零后，比赛结束，另一方获得本场胜利。

牌型基础奖励与基础筹码经济属于《超限德州》的固定规则，适用于全部游戏模式，与技能系统是否开启无关。

二、牌局流程

每手开始时，一名玩家位于庄家位并支付小盲注，另一名玩家支付大盲注。每手结束后，庄家位置互换。

  • 翻牌前由庄家位（小盲位）首先行动；
  • 翻牌后由大盲位首先行动。

每名玩家获得两张仅本人可见的底牌。随后按以下街道进行：

  1. 翻牌前 Pre-Flop：仅持有底牌，进行第一轮下注。
  2. 翻牌 Flop：发出三张公共牌，再进行下注。
  3. 转牌 Turn：发出第四张公共牌，再进行下注。
  4. 河牌 River：发出第五张公共牌，再进行下注。
  5. 摊牌 Showdown：双方均未弃牌时，比较最终牌型。

当前街道下注结束后进入下一街道。若双方已无后续下注行动，系统直接发出剩余公共牌并进入摊牌。

三、玩家行动

系统只提供当前牌局状态允许的行动。玩家只能执行界面给出的合法选项。

过牌 Check
当前无需跟注时，不增加投入并结束本次行动。
下注 Bet
本街道尚无人下注时，投入一定数量的筹码。
跟注 Call
补足差额，使自己的本轮投入与对手当前下注匹配。
加注 Raise
在已有下注上提高金额。须满足当前最小加注，且不超过可投入上限。
弃牌 Fold
放弃本手。对手立即赢得该手，不比较牌型。
全下 All In
投入当前规则允许的最大筹码。后续处理以牌局状态及特殊技能为准。

四、手牌胜负

一手牌以弃牌或摊牌结束。

弃牌

一名玩家弃牌后，对手立即赢得该手。弃牌结束的手牌不比较牌型，也不发放牌型基础奖励。

摊牌

双方均未弃牌并完成最后一轮下注后进入摊牌。每名玩家从七张牌中组成最高的五张牌：

  • 本人两张底牌；
  • 五张公共牌。

可以使用零张、一张或两张底牌。牌型较高的一方获胜；类别相同时，按标准德州扑克规则比较该牌型中的点数。双方最终五张完全相同则为平局。

所有花色地位相同，不存在花色高低。

五、牌型等级

由高到低如下。皇家同花顺在本系统中为独立等级，高于普通同花顺。

六、牌型基础奖励

牌型基础奖励属于基础规则，适用于全部模式。仅在摊牌产生唯一胜者时，按胜者最终牌型发放。

普通弃牌、撤退弃牌与平局均不获得该奖励。奖励是玩家之间的额外筹码转移，不会增加比赛筹码总量。

示例：标准净转移 500，胜者以三条获胜：

500 + 25 = 525

若同时存在合法的 ×2 结算倍率：

525 × 2 = 1050

实际转移不得超过败方能够支付的筹码。

七、技能构筑

启用技能系统时，须在开赛前完成构筑，且本场不可更换。

  • 装备 1 至 4 个技能；
  • 总负载不超过 8；
  • 同一技能不得重复装备。

开赛时，对手不会获知你的装备数量、总负载或完整技能列表。

技能分为公开与秘密。公开技能发动后按规则向双方展示相关信息；秘密技能通常仅发动者知晓，直到被公开发动、被侦察、产生可观察效果，或满足其他揭露条件。

负载、费用、可用阶段、次数与具体效果以技能档案中的对应说明为准。

八、能量

能量用于支付主动技能及部分特殊效果。普通情况下起始为 4，上限为 8。装备「天命」的玩家，真实能量上限提高至 10。

九、对手能量信息

对手的真实能量默认不实时公开。每手全部资源结算完成后，系统更新一次对手公开能量；该值在下一手进行期间保持不变，直到下一次手牌结束。

普通公开能量范围为 0 至 8：

  • 真实能量低于 0 时，公开显示为 0；
  • 真实能量为 0 至 8 时，按实际值显示；
  • 真实能量为 9 或 10 时，公开显示为 8。

你始终可以查看自己的真实当前能量。具有明确资源侦察效果的技能，可按技能说明读取对手真实能量。

十、筹码与标准结算

筹码最小单位为 1。所有正式筹码状态均按整数结算。

标准筹码结算依次考虑：

  1. 标准德州扑克产生的净筹码转移；
  2. 牌型基础奖励；
  3. 其他合法的基础加值；
  4. 合法的筹码倍率；
  5. 防守及其他最终损失修正；
  6. 败方实际可支付筹码上限。

若计算产生非整数，按相应规则整数化。同一笔玩家间转移始终以相同整数从支付方扣除并计入接收方，因此比赛筹码总量保持不变。

十一、标准筹码与直接技能转移

部分技能造成的筹码变化属于直接技能转移：不计入标准德州扑克净收益，也不参与普通筹码倍率。

包括但不限于：「贷款」直接取得的筹码、贷款偿还，以及「终局」对未匹配投入的没收。

除技能明确规定外，直接技能转移不会因标准结算倍率再次放大，也不会因普通下注退款而自动撤销。

十二、全下与未匹配投入

玩家全下后，如双方均已无合法后续下注行动，系统将依次发出剩余公共牌并进入摊牌。

在双人牌局中，标准下注只有双方能够匹配的部分参与正常争夺。一方超出对手可匹配范围的未匹配投入，按当前牌局规则处理；若特殊技能明确改变处理方式，则以该技能为准。

《超限德州》为双人对战，不采用多人德州扑克中的多重边池体系。

十三、平局

摊牌时双方最终最佳五张完全相同，该手判定为平局。

  • 双方不获得牌型基础奖励；
  • 胜利倍率不触发；
  • 标准争夺筹码按规则返还或平均分配；
  • 双方均不获得普通失败能量恢复。

特殊技能另有规定的除外。

十四、特殊状态与已完成效果

部分技能可建立持续状态、修改牌面、改变牌堆、限制行动或影响最终结算。

除技能明确规定外：

  • 已经完成的牌张交换不会自动恢复；
  • 已经完成的牌堆修改不会自动恢复；
  • 已经获得的信息不会被遗忘；
  • 已经完成的直接筹码转移不会自动撤销。
清除持续技能状态，不等同于回滚已经完成的游戏事实。

十五、规则优先级

标准德州扑克规则构成《超限德州》的基础牌局规则。当技能或特殊状态明确修改基础规则时，以对应的具体规则为准。

不同层级发生直接冲突时，按以下顺序适用：

  1. 特殊状态或明确例外规则
  2. 具体技能规则
  3. 《超限德州》基础规则
  4. 标准德州扑克通用规则

系统依据当前牌局状态确定可执行的合法行动与可发动的技能。玩家只能执行当前规则允许的操作。
